Build and Toolchain

Nexium uses CMake 3.30+, C++26, and vendored dependencies. The standard Ninja build produces the editor-enabled TemplateGame.

  • CMake structure explains targets, options, generation, and checks.

  • CI records what the current workflow actually runs.

  • Module graph lists the public libraries.

CMake’s C26 feature check verifies compiler mode availability, not support for every C26 language/library feature. Check features on the actual GCC, Clang, and MSVC toolchains before adopting them.

The normal build does not enable tests or benchmarks automatically. Standalone game delivery and cross-compiling the JRM tool are not current workflows.

Nexium Engine

A lightweight, cross-platform 3D game engine designed for modern C++ development. Nexium Engine is currently in active development and aims to provide a flexible, high-performance foundation for building real-time 3D applications without the overhead of traditional heavyweight engines.

What is Nexium Engine?

Nexium Engine is a feature-rich, cross-platform 3D engine with a unified workflow. The goal is simple: provide strong, modern tools so developers can focus on creating games rather than reinventing rendering systems, asset pipelines, windowing layers, or platform backends.

Once stable, Nexium will support exporting projects to major desktop and mobile platforms:

  • Linux

  • Windows

  • Android

Nexium emphasizes:

  • modern C++ architecture (C++23, clean memory model, shared/static runtime separation)

  • high-performance rendering (OpenGL for now, planned Vulkan backend)

  • clean module separation (Core, Math, Rendering, Windowing, ECS, Resources)

  • strict cross-platform behavior

  • simple, unified build system (CMake)

Open Source

Nexium Engine is 100% free and open-source under the MIT license.

  • No royalties.

  • No locked features.

  • Your game belongs entirely to you.

Nearly the entire engine (~99.9%) is developed by Valerii Koniushenko.

Getting the Engine

Because Nexium is under rapid development, binary releases are not yet provided. However, the engine builds easily from source using standard toolchains. I tried to make the process the building as easy as it is possible. So, just choose your platform & let’s go!

Windows

Requirements

  1. CMake 3.6+

  2. MSVC 14+ (Visual Studio 2022 recommended)

Build Steps

git clone https://github.com/ValeriiKoniushenko/Nexium.git
cd Nexium
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build

To run, just open this file:

build/Debug/bin/TemplateGame

Linux

Requirements

  1. CMake 3.6+

  2. Clang 19+ | GCC 14+

  3. Install required system libraries (Ubuntu example):

sudo apt install libwayland-dev libx11-dev libxi-dev libxrandr-dev libxinerama-dev libxkbcommon-dev libxcursor-dev libgl1-mesa-dev

Build Steps

git clone https://github.com/ValeriiKoniushenko/Nexium.git
cd Nexium
cmake -S . -B build
cmake --build build

To run, just open this file:

build/bin/TemplateGame

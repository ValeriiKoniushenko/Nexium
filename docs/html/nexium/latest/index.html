Nexium Engine

Nexium is a personal C++ game engine and ImGui editor for games made by a team of 1–3 developers. The current focus is creating 2D games inside this repository, with optional 3D support.

Current foundation

  • OpenGL rendering, orthographic/perspective cameras, grids, textures, and optional meshes.

  • Reflected component trees through JustReflectMe.

  • ImGui docking, scene tree, property adapters, asset browser, and viewport picking.

  • CMake libraries organized into Foundation, Platform, RawBackend, Fundamental, Subsystems, World, Runtime, and Editor.

The example application is editor-enabled. Game-only building/delivery remains later work. Render-mode switching currently shares the authored scene; it is not an isolated Play/Stop workflow.

Documentation

Start with Architecture, Gameplay, Rendering, and CMake infrastructure. The architecture pages distinguish implemented behavior from recommendations.

Build requirements are CMake 3.30+ and a compiler with the configured C++26 mode. Linux uses GCC/Clang; MSVC compatibility remains a target requiring validation. Source and dependencies are available in the repository. The repository LICENSE is Apache-2.0.

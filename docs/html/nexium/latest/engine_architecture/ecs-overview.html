Component System

Nexium’s ECS is a reflected component tree with cloning, traversal, and a type factory. It does not use archetype storage or a central query scheduler.

Types and ownership

AbstractComponent supplies reference counting, enable/no-tick flags, tick dispatch, and serialization. BaseComponent adds a name, type, child ownership, parent observation, and initialization.

Scene owns root SceneObject instances, which combine BaseComponent with transforms, drawing, outlining, and persistence. Children can be non-spatial components. Actor, cameras, rectangles, and editor widgets specialize this tree model.

Registration and reflection

Macro Purpose

CLASS(), ENUM_CLASS(), FIELD()

JRM metadata annotations.

ECS_DECL / ECS_IMPL

Declare and implement typed pointers, creation, cloning, registration, and the reflection bridge.

ECS_DECL_NO_CNSTR

Use a caller-defined constructor.

ECS_DECL_NO_SER / ECS_IMPL_NO_SER

Omit the reflection bridge.

ECS_DECL_NO_SER_NO_CNSTR

Combine both declaration variants.

ECS_TEMPLATE_COMPONENT_DECL / ECS_TEMPLATE_COMPONENT_IMPL

Template-component variants.

ECS_IMPL registers a creator during static initialization of componentType. There is no hand-maintained type list or linker-section registration in these macros. WHOLE_ARCHIVE linking retains registration translation units; JRM separately generates metadata. Never edit generated files. The JRM adapter is dependencies/JustReflectMe/sources/JustReflectMe/Adapter.h.

Serialized non-template type names must remain compatible with saved content. Template registration uses typeid names, which are not portable content identifiers.

Working with children

Operation Behavior

addChildComponent<T>()

Create a child, establish its parent link, and initialize it; initialize the parent first if needed.

attachChild()

Clone the supplied child tree into this parent.

addUniqueTypeChildComponent<T>()

Reuse a direct child castable to T, otherwise create one.

detachChild() / removeChild()

Release a direct child and clear its parent link; another strong reference can keep it alive.

forEach() / forEachDFS()

Visit descendants in breadth/depth-first order; exclude the starting node.

getOwner()

Return the topmost component ancestor, or itself for a root.

initialize() runs hooks and initializes children once, until invalidated. tick() only checks enabled/no-tick flags; it does not require initialization. The default BaseComponent::onTick() ticks children, so derived overrides must call the base hook when that propagation is wanted. A disabled/no-tick parent stops this default path.

Copies clone descendants; concrete macro-generated clones invalidate their initialized state. Derived resource and subscription ownership still needs explicit copy behavior.

Persistence

JRM serializes reflected state and child trees. Scene adds instance records described in Scenes. Names are editable, and makeHash() depends on ancestor names; neither is a stable identity across rename or reparenting.

Implementation: NxFundamental/ECS/BaseComponent.{h,cpp}. tests/ECSTests/ECSTests.cpp covers factories, serialization, traversal, cloning, and parent repair; tests/Runtime/RuntimeTests.cpp checks retained World registrations.

This reference describes the routed input API in namespace NX. Declarations are included from the current headers. The accompanying tables document behavior and preconditions that cannot be inferred from a signature alone.

Include headers from NxWorld/Framework/Input/ for world-level input/controller types and NxSubsystems/Input/InputTypes.h for shared event/chord types. Use Core intrusive/weak pointers and StringAtom names as elsewhere in the engine.

InputController

An ECS BaseComponent, not a BaseController subclass. It owns editable bindings, independent runtime state, handlers, and its action delegate. ECS_DECL additionally supplies pointer aliases, constructors, componentType, Create(), and clone().

Creation and lifecycle

API Contract

Macro-provided constructor / Create()

Allocate a component with default Gameplay context. The no-argument factory does not initialize.

Constructor(name, context)

Set the component name/context; constructor alone does not initialize.

Create(name, context)

Allocate and initialize before returning the intrusive Ptr.

initialize / deinitialize

Inherited component lifecycle; input registers/unregisters in the corresponding hooks.

Destructor

Unregister from InputSystem.

Copy/clone

Copy configuration and explicit enable flag; fresh runtime, handlers, delegate and registration.

Assignments/moves

Deleted for InputController.

Keep a real owner alive; router registration is non-owning.

Binding configuration

API Contract

bind(action, chord, trigger)

Create a Button binding; trigger defaults to OnPress.

bind(action, chord, callback, trigger)

Same binding operation; a nonempty callback installs/replaces that action’s handler. An empty callback in this overload does not remove an existing handler.

bind(Binding)

Allow all supported source types. Validate minimum shape, cancel current state, replace first matching action or insert, then refresh.

bind return value

True for insertion; false for valid replacement or invalid binding.

unbind(action)

Remove all bindings of that name; true if removed. Cancellation/refresh occurs only when removed.

clearBindings()

Cancel all state and clear bindings; handlers remain.

setBindings(vector)

Copy all entries, including invalid or duplicate entries; cancel all state and refresh. Resolution skips invalid entries. Self-aliasing with getBindings is safe.

getBindings()

Const vector reference. Later changes can invalidate its contents/references.

getInputMap()

Return a configuration copy.

setInputMap(map)

Copy its vector through setBindings; no shared runtime.

Binding changes reset all actions on that input component, not just the named action. Repeated bind calls are replacements, not a way to accumulate alternate keys.

Context and enable state

API Contract

setInputContext / getInputContext

Assign/query one enum identity. A changed value cancels and refreshes; same value is a no-op.

setInputEnabled

Changed explicit flag cancels and refreshes; same value is a no-op.

isInputEnabled

True only if the explicit flag, this component, and all ancestors are enabled. Does not test initialization, context availability, focus, or ticking.

Use context policy to decide delivery, not isInputEnabled as a context-reachability query.

Action queries

API Return behavior

isActive(action)

False for unknown/inactive action or disabled input. Otherwise the binding-defined held/transient activity.

isActionPressed(action)

Compatibility alias of isActive. It does not specifically mean an OnPress edge.

getActionValue(action)

Accumulated vec2, or zero for unknown/inactive/disabled input. Button contributions are (1,0), pointer/scroll contributions preserve their event values.

getActionModifiers(action)

OR of contributing binding snapshots, or None for unknown/inactive/disabled input.

Held modifiers are captured at activation, not continuously rewritten when an unrelated modifier changes. A release pulse uses the release event’s modifier snapshot. For a current physical modifier-dependent behavior, bind a separate held modifier action or design the consumer’s command data explicitly. Queries do not consume pulses.

Notifications and settings

API/field Contract

setActionCallback(action, callback)

Install/replace a nonempty handler; empty handler removes it; empty action is ignored.

onAction

Intrusive delegate initially created for the component. Receives emitted actions after the action-specific callback.

speed

Reflected float, default 600. Used by consumers such as Spectator.

mouseSensitivity

Reflected float, default 0.5. Core input does not apply it to values.

getTags()

BaseComponent tags plus Tag_InputController.

onPostDeserialize

Base processing followed by silent cancellation and router refresh.

Callbacks are synchronous and not copied/serialized. Cancellation emits no notification.

Configuration API excerpt; private storage omitted.
class InputMap
{
public:
    InputMap() = default;
    explicit InputMap(std::vector<InputBinding> bindings)
        : _bindings(std::move(bindings))
    {
    }

    [[nodiscard]] const std::vector<InputBinding>& getBindings() const noexcept
    {
        return _bindings;
    }

    void setBindings(std::vector<InputBinding> bindings) { _bindings = std::move(bindings); }

    bool bind(InputBinding binding) { return Bind(_bindings, std::move(binding)); }
    bool unbind(const Core::StringAtom& action) { return Unbind(_bindings, action); }

    [[nodiscard]] std::optional<InputBinding> resolveBinding(const KeyInputEvent& event) const
    {
        return ResolveBinding(_bindings, event);
    }

    [[nodiscard]] static bool IsValid(const InputBinding& binding);
    static bool Bind(std::vector<InputBinding>& bindings, InputBinding binding);
    static bool Unbind(std::vector<InputBinding>& bindings, const Core::StringAtom& action);
    [[nodiscard]] static std::optional<InputBinding> ResolveBinding(
        std::span<const InputBinding> bindings, const KeyInputEvent& event);
API Contract

Default constructor

Empty vector.

Vector constructor / setBindings

Move supplied configuration into the map; no validation pass.

getBindings

Const reference to configuration.

bind / static Bind

Minimum validation; replace first same-action entry or append. True only for append.

unbind / static Unbind

Erase all same-action entries; true if any were removed.

resolveBinding / static ResolveBinding

Return a copied optional winning binding. Match source/chord, prefer greatest requirement count plus nonempty trigger, and keep first tie.

IsValid

Nonempty action, plus non-None trigger for Button.

to_json / from_json

Custom InputBinding adapters; see Serialization.

Map resolution does not process frame state or emit events. It is not itself a complete dispatcher: the router filters event states and runtime activation semantics.

InputSystem

GetInputSystem() returns the singleton. The public methods include engine integration and lifecycle plumbing; gameplay normally uses its own input component.

[[nodiscard]] InputContextGuard pushContext(InputContextLayer layer);

API Contract

initialize(window)

Subscribe the collector once. Current design supports one bound window.

processEvents()

Start an input frame and drain queued events. Call once before consumers tick.

setActiveContext(context)

Change base context and immediately synchronize when changed.

setGlobalContext(optional)

Set/remove the optional layer above base; synchronize when changed.

pushContext(layer)

Push temporary overlay, synchronize, return owning move-only guard.

resetInput()

Clear queue/devices/actions/pointer ownership/quarantine/recording fence. Preserve bindings, handlers, registration, contexts and live capture guards.

hasPointerCapture()

Whether any router registration has accepted pointer-button ownership.

registerController(pointer)

Internal ECS plumbing: non-owning, ignore null/duplicate registration, refresh availability.

unregisterController(pointer)

Remove matching registrations.

refreshController(pointer)

Invalidate pending binding candidates, reset gesture/availability state, synchronize. The configuration-facing InputController methods supply their own cancellation.

Do not register ordinary components manually to bypass lifecycle, or call refreshController instead of the public binding/context/enable setters. There is no public physical-key polling, context-stack inspection, per-player instance creation, or action injection API on InputSystem.

InputContextGuard

Public guard excerpt.
class InputContextGuard
{
public:
    InputContextGuard() = default;
    InputContextGuard(const InputContextGuard&) = delete;
    InputContextGuard& operator=(const InputContextGuard&) = delete;
    InputContextGuard(InputContextGuard&& other) noexcept;
    InputContextGuard& operator=(InputContextGuard&& other) noexcept;
    ~InputContextGuard();
    void reset();

Default construction is empty. Copy is deleted; move transfers a layer ID and its borrowed owner. Move assignment first resets the destination’s old layer. reset/destruction remove the owned overlay once, even out of stack order. The owner must outlive every guard.

API Contract

setActiveContext / setGlobalContext

Return true only when changed. The value type alone does not synchronize a router.

push(layer)

Return a monotonically allocated uint64 LayerId.

pop(id)

Remove that ID, regardless of stack position; true if it existed.

getLayers()

Return a vector copy: reversed overlays, optional distinct global, base.

isAvailable(context, channel)

Reach matching context before an earlier BlockLower on the selected channel. Does not resolve ConsumeMatched maps.

InputSystem owns the operational stack. Use its methods/guards for live routing.

Buttons, channels, modifiers, and events

ENUM_CLASS();
enum class InputContext : std::uint8_t
{
    Editor,
    Gameplay,
    EditorViewport,
    Modal,
    TextInput,
    BindingCapture
};

enum class InputChannel : std::uint8_t
{
    Keyboard = 1,
    Pointer = 2,
    All = 3
};

[[nodiscard]] constexpr bool hasInputChannel(InputChannel mask, InputChannel channel) noexcept
{
    return (static_cast<std::uint8_t>(mask) & static_cast<std::uint8_t>(channel)) != 0;
}

enum class InputEventType : std::uint8_t
{
    Button,
    PointerMove,
    Wheel
};

ENUM_CLASS();
enum class InputModifier : std::uint8_t
{
    None = 0,
    Shift = 1 << 0,
    Control = 1 << 1,
    Alt = 1 << 2,
    Super = 1 << 3,
    All = (1 << 4) - 1
};

hasInputChannel(mask, channel) tests any overlapping bit; when supplied All as the second argument it does not mean “both bits are present”. Modifier | and & operators are defined in the global namespace.

class InputButton
{
public:
    constexpr InputButton() = default;
    constexpr InputButton(Platform::Keyboard::Key key)
        : _value(key)
    {
    }
    constexpr InputButton(Platform::Mouse::Key button)
        : _value(button)
    {
    }

    [[nodiscard]] constexpr bool isMouse() const noexcept
    {
        return std::holds_alternative<Platform::Mouse::Key>(_value);
    }

    [[nodiscard]] constexpr Platform::Keyboard::Key getKeyboardKey() const noexcept
    {
        if (const auto* key = std::get_if<Platform::Keyboard::Key>(&_value))
        {
            return *key;
        }
        return Platform::Keyboard::Key::None;
    }

    [[nodiscard]] constexpr Platform::Mouse::Key getMouseButton() const noexcept
    {
        if (const auto* button = std::get_if<Platform::Mouse::Key>(&_value))
        {
            return *button;
        }
        return Platform::Mouse::Key::None;
    }

    [[nodiscard]] constexpr bool isNone() const noexcept
    {
        return isMouse() ? getMouseButton() == Platform::Mouse::Key::None
                         : getKeyboardKey() == Platform::Keyboard::Key::None;
    }

    [[nodiscard]] constexpr bool operator==(const InputButton&) const noexcept = default;

private:
    std::variant<Platform::Keyboard::Key, Platform::Mouse::Key> _value
        = Platform::Keyboard::Key::None;
};

[[nodiscard]] InputButton NormalizeInputButton(InputButton button) noexcept;
[[nodiscard]] bool IsInputModifier(InputButton button) noexcept;

InputButton defaults to keyboard None. Accessing the other device variant returns that device’s None. NormalizeInputButton() aliases the four right modifiers to left; IsInputModifier() identifies logical Shift/Control/Alt/Super.

struct InputActionEvent
{
    Core::StringAtom action;
    Platform::Keyboard::KeyState state = Platform::Keyboard::KeyState::None;
    glm::vec2 value{};
    glm::vec2 position{};
    bool canceled = false;
    InputModifier modifiers = InputModifier::None;

    [[nodiscard]] constexpr bool isCanceled() const noexcept { return canceled; }

    [[nodiscard]] constexpr bool isPressed() const noexcept
    {
        return state == Platform::Keyboard::KeyState::Pressed;
    }

    [[nodiscard]] constexpr bool isReleased() const noexcept
    {
        return state == Platform::Keyboard::KeyState::Released;
    }

    [[nodiscard]] constexpr bool isRepeated() const noexcept
    {
        return state == Platform::Keyboard::KeyState::Repeated;
    }
};
Field/helper Meaning

KeyInputEvent.key/state/scancode

Physical event identity/state and retained scancode; key is normalized after device processing.

KeyInputEvent.pressedKeys

Normalized current held-button snapshot after applying that event.

KeyInputEvent.modifiers

Reconstructed from physical modifier sides by device state.

KeyInputEvent.type/value/position

Event family, pointer delta/scroll offset, window cursor position.

InputActionEvent.action

Configured semantic atom.

InputActionEvent.value

Individual emitted contribution, not a frame’s accumulated polling total.

InputActionEvent.state

Pressed for Button activation; Released for an accepted OnRelease chord ending; normally None for pointer/wheel.

InputActionEvent.modifiers/position

Activation snapshot, or current release snapshot for OnRelease.

isPressed / isReleased

Check event state only; they are not named-action polling APIs.

canceled / isCanceled

Present in the structure; current silent cancellation emits no canceled events.

isRepeated

Checks the field, but routed Button Repeat is ignored.

InputCapture

Public recording-capture excerpt.
class InputCapture
{
public:
    InputCapture();
    ~InputCapture();

    InputCapture(const InputCapture&) = delete;
    InputCapture(InputCapture&&) = delete;
    InputCapture& operator=(const InputCapture&) = delete;
    InputCapture& operator=(InputCapture&&) = delete;

    /// Returns whether a guard exists or held buttons are still awaiting release.
    [[nodiscard]] static bool isActive() noexcept;

    /// Tracks button presses and releases, even when no guard exists.
    static void updateButton(InputButton button, Platform::Keyboard::KeyState state);

    /// Clears button tracking and pending releases without ending live captures.
    static void resetButtons();

Construction increments a global guard count. Copy/move are deleted. Destruction of the last guard establishes a pending-release fence if physical holds remain. isActive is true for a live guard or that fence. updateButton tracks Press/Release even without a live guard. resetButtons clears physical tracking/fence but not the guard count. These integration methods are not an actor-control mechanism.

Domain controller API

See Controller hierarchy for the type graph, ownership, and GameController/HumanController/EditorController declaration excerpts. BaseController and AIController add no public input API of their own. Inherited component lifecycle and GameController’s possession hooks are their extension points.

Internal collaboration

InputCollector, InputDeviceState, InputRouter, and InputActionRuntime are separated implementation collaborators. Ordinary gameplay should not call their methods to bypass InputSystem or alter private acceptance state. Their actual processing order and contracts are documented in Lifecycle and Routing.

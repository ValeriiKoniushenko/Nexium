Platform Input privately links Platform Graphics. RawBackend privately links Core::Stb. Subsystem Graphics privately links Utils::Utils. AssimpImporter privately links assimp::assimp; World additionally exposes Assimp and the importer when 3D is enabled. AssetsManager privately links comdlg32 on Windows.

Nexium::Fundamental is an INTERFACE aggregate of its five focused targets. Nexium::NxFundamental, Nexium::NxWorld, and Nexium::NxRuntime preserve old aliases. Nexium::World::Scene aliases World; it is not a separate scene library.

The application chain is TemplateGame → Editor → Runtime → World. TemplateGame retains Editor with WHOLE_ARCHIVE. WHOLE_ARCHIVE retains otherwise unreferenced component registrations in these static libraries.

Owns lighting/time and game/player/level state; observes currentCamera. Scene is its sibling, not its child.

Owns root SceneObjects through intrusive pointers, plus grid/skybox state.

BaseComponent

Owns children through intrusive pointers; observes its parent.

ObjectSelectorManager

Holds strong pointers to selected components, keyed by addresses.

Source anchors: Framework/{GameInstance,World}.h, Scene/Scene.h in NxWorld, NxFundamental/ECS/BaseComponent.h, and Editor/EditorIntegration.h.

Boundary limits

ApplicationIntegration lets Runtime and World call editor hooks without including Editor implementation headers.

RawBackend’s IDrawable still names higher-layer camera/actor/mesh types through forward declarations. Scene::directDraw chooses the camera and editor grid through global GameInstance/World access.

Public header sets support compilation checks, but the shared sources/ include root also exposes private headers. “Subsystem” currently means a service library, not automatic lifetime management.

See CMake infrastructure and recommended boundaries.

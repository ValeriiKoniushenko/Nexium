[[engine architecture]] = (draft, migrating) Engine Architecture

New engine architecture is totally reworked and original architecture can be found by the next SHA c6f0d00b4fc2bb348c69b37093bd928324b0b161.

The goal of the reworking is to fix the globall architecture and dependency mess. Everything was connected to each other, a lot of modules were spreaded though the whole project. It doesn’t even make a sense to describe how it was.

Now, everything is devided by layers.

# Rule: dependencies only ever point downward (higher number -> lower number). Never the reverse.
# Exception: Foundation (1) is a shared kernel, callable directly from any layer (math, logging, config).
# Extensions/Plugins inherit their host layer's rules — no quiet exceptions for "just this once."

8 Editor              -> ImGui UI, in-editor windows; attaches to a running Runtime like a debugger (pause/step/inspect — a good fit for reflection-driven access via JustReflectMe rather than hard #includes); never linked into the shipped build
7 Nexium Runtime      -> mainloop; orchestrates World and Nexium Subsystems (Assets/Render/Audio/Input)
6 Nexium World        -> World, GameInstance, Actor, Pawn, Controller (consumes Subsystems' Input System, AI), Skybox, gameplay primitives, animations, Extensions/Plugins (e.g. Physics)
5 Nexium Subsystems   -> Camera, Asset management, Atlas, non-raw render (ShaderManager), Texture/Image, 2D/3D model impls, Audio work, Input System (wraps Platform's raw input)
4 Nexium Fundamental  -> ECS, Asset Registry, File I/O handling, raw de/serialization
3 Raw Backend         -> render API, render graph/commands, OpenGL backend, raw audio work
2 Platform            -> Window class & logic, filesystem, raw input system
1 Foundation          -> Core (StringAtom, Math, common classes/structs), Logging (spdlog), Config

1 - Foundation

  • Target name: Nexium_Foundation (Nexium::Foundation)

  • Cmake dependency: Utils::Utils, Utils::Core (StringAtom, Math, Delegates, etc). Path to module: dependencies/Utils

  • The files: Foundation/Configs., Foundation/BaseLog.

  • Path to this module is: sources/Foundation

2 - Platform

It has three main targets. 1. Private: Nexium_Platform_PrivateModule - It includes: sources/Platform/PrivateModuleInfo. - Cmake dependency is: Nexium::Foundation 2. Public: Nexium_Platform_Graphics (Nexium::Platform::Graphics) - It includes: sources/Platform/{Graphics}. - Cmake dependency is: glfw, Core::Glad 3. Public: Nexium_Platform_Input (Nexium::Platform::Input) - It includes: sources/Platform/{Keyboard,Mouse,Window}.* - Cmake dependency is: Nexium::Foundation, Nexium::Platform::Graphics

  • Path to these modules is: sources/Platform

3 - Raw Backend

It has one target. 1. Public: Nexium_RawBackend (Nexium::RawBackend) - It includes: sources/RawBackend/{Image,IDrawable}.* - Cmake dependency is: Nexium::Foundation, Core::Stb (dependencies/Stb)

  • Path to these modules is: sources/RawBackend

4 - Nexium Fundamental

It has one private target, five focused public targets, and one aggregate compatibility target.

  1. Private: Nexium_Fundamental_PrivateModule

    • It includes: sources/NexiumFundamental/PrivateModuleInfo.*

    • CMake dependency is: Nexium::Foundation

  2. Public base: Nexium_Fundamental_Base (Nexium::Fundamental::Base)

    • It includes: sources/NexiumFundamental/{ITagHolder,Transformable}.*

    • CMake dependency is: Nexium::Foundation

  3. Public resource management: Nexium_Fundamental_ResourceManagement (Nexium::Fundamental::ResourceManagement)

    • It includes: sources/NexiumFundamental/ResourceManagement/{DataStream,JsonAdapter}.*

    • CMake dependency is: Nexium::Foundation

  4. Public ECS: Nexium_Fundamental_ECS (Nexium::Fundamental::ECS)

    • It includes: sources/NexiumFundamental/ECS/BaseComponent.*

    • CMake dependency is: Nexium::Fundamental::Base, Nexium::Fundamental::ResourceManagement

  5. Public assets: Nexium_Fundamental_Assets (Nexium::Fundamental::Assets)

    • It includes: sources/NexiumFundamental/Assets/{BaseAsset,ECSAsset}.*

    • CMake dependency is: Nexium::Fundamental::ECS, Nexium::Fundamental::ResourceManagement

  6. Public texture atlas: Nexium_Fundamental_TextureAtlas (Nexium::Fundamental::TextureAtlas)

    • It includes: sources/NexiumFundamental/Assets/TextureAtlas.*

    • CMake dependency is: Nexium::Foundation, Nexium::RawBackend, Core::Rectpack2D

  7. Aggregate compatibility target: Nexium_Fundamental (Nexium::Fundamental)

    • It links all five public targets. New consumers should link the narrowest target they need.

    • Nexium::NexiumFundamental remains as a temporary alias for the former target name.

    • Path to these modules is: sources/NexiumFundamental

Notes

  • One layer == One folder inside sources/<layer_name>. But, it doesn’t mean that every layer is built from one CMake module/taget. It easily may be more than one.

  • Every layer (folder) conain its' own totally private module. The name of this module it: Nexium_<layer_name>_PrivateModule. The sense of it is to contain PrivateModuleInfo.{h,cpp} with all related to module information: module name, logger synk

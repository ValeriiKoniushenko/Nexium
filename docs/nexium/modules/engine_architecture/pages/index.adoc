= Architecture Overview
:page-role: landing

Nexium is a personal game engine and editor for games made by 1–3 developers.
Games currently live in the engine repository.
The immediate goal is a useful 2D authoring workflow; optional 3D and game-only delivery can follow.

== Design direction

Keep the existing eight layers, focused libraries, JRM reflection, and component trees.
Make world ownership, editing operations, and simulation lifetimes explicit before expanding the gameplay framework.
Build dependencies and object ownership are separate graphs.

The current application links Editor and shares one scene between editor and game rendering.
UE-style class names describe intended roles; they do not establish UE-equivalent behavior.

Platform Input privately links Platform Graphics.
RawBackend privately links Core::Stb.
Subsystem Graphics privately links Utils::Utils.
AssimpImporter privately links assimp::assimp; World additionally exposes Assimp and the importer when 3D is enabled.
AssetsManager privately links comdlg32 on Windows.

`Nexium::Fundamental` is an INTERFACE aggregate of its five focused targets.
`Nexium::NxFundamental`, `Nexium::NxWorld`, and `Nexium::NxRuntime` preserve old aliases.
`Nexium::World::Scene` aliases World; it is not a separate scene library.

The application chain is `TemplateGame -> Editor -> Runtime -> World`.
TemplateGame retains Editor with WHOLE_ARCHIVE.
This protects registration translation units from archive extraction, at the cost of retaining the entire selected archive.
It does not create dynamically loadable modules.

== Runtime ownership

[cols="2,5",options="header"]
|===
|Owner or observer |Current relationship
|`gGameInstance` |Application-owned unique pointer to GameInstance.
|GameInstance |Owns gameScene, world, assets, userInterface as members; references the shared ShaderManager and Platform Window.
|Runtime |Borrows GameInstance by reference.
|EditorIntegration |Borrows Runtime; owns GameEditor, ObjectSelectorManager, ObjectPickerAggregator.
|GameInstance integration pointer |Borrows ApplicationIntegration; attachment/detachment is explicit.
|World |Owns lighting/time and game/player/level state; observes currentCamera. Scene is its sibling, not its child.
|Scene |Owns root SceneObjects through intrusive pointers, plus grid/skybox state.
|BaseComponent |Owns children through intrusive pointers; observes its parent.
|ObjectSelectorManager |Holds strong pointers to selected components, keyed by addresses.
|===

Source anchors: `Framework/{GameInstance,World}.h`, `Scene/Scene.h` in NxWorld,
`NxFundamental/ECS/BaseComponent.h`, and `Editor/EditorIntegration.h`.

== Boundary limits

Runtime and World do not include Editor implementation headers.
ApplicationIntegration supplies editor hooks through a lower-layer interface.
This is a useful dependency inversion.

RawBackend's IDrawable still names NX::BaseCamera, Actor, and StaticMesh.
Forward declarations remove a direct build requirement but retain knowledge of higher-level concepts.
Scene::directDraw also chooses the camera and editor grid through global GameInstance/World access.

Public header sets use the shared sources include root.
They describe headers and enable compilation checks, but do not prevent consumers from including another module's private headers.
“Subsystem” currently means a service library, not automatic lifetime management.

See xref:build:cmake-structure.adoc[CMake infrastructure] and xref:ue5-alignment.adoc[recommended boundaries].

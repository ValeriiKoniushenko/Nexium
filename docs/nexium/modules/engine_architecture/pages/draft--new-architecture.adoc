[[engine architecture]]
= (draft, migrating) Engine Architecture

New engine architecture is totally reworked and original architecture can be found by the next SHA `c6f0d00b4fc2bb348c69b37093bd928324b0b161`.

The goal of the reworking is to fix the globall architecture and dependency mess. Everything was connected to each other, a lot of modules were spreaded though the whole project. It doesn't even make a sense to describe how it was.

Now, everything is devided by layers.

```
# Rule: dependencies only ever point downward (higher number -> lower number). Never the reverse.
# Exception: Foundation (1) is a shared kernel, callable directly from any layer (math, logging, config).
# Extensions/Plugins inherit their host layer's rules — no quiet exceptions for "just this once."

8 Editor              -> ImGui UI, in-editor windows; attaches to a running Runtime like a debugger (pause/step/inspect — a good fit for reflection-driven access via JustReflectMe rather than hard #includes); never linked into the shipped build
7 Nexium Runtime      -> mainloop; orchestrates World and Nexium Subsystems (Assets/Render/Audio/Input)
6 Nexium World        -> World, GameInstance, Actor, Pawn, Controller (consumes Subsystems' Input System, AI), Skybox, gameplay primitives, animations, Extensions/Plugins (e.g. Physics)
5 Nexium Subsystems   -> Camera, Asset management, Atlas, non-raw render (ShaderManager), Texture/Image, 2D/3D model impls, Audio work, Input System (wraps Platform's raw input)
4 Nexium Fundamental  -> ECS, Asset Registry, File I/O handling, raw de/serialization
3 Raw Output          -> render API, render graph/commands, OpenGL backend, raw audio work
2 Platform            -> Window class & logic, filesystem, raw input system
1 Foundation          -> Core (StringAtom, Math, common classes/structs), Logging (spdlog), Config
```

== 1 - Foundation

It includes:
- The dependecy cmake modules Utils::Utils, Utils::Core (StringAtom, Math, Delegates, etc). Path to module: `dependencies/Utils`
- The files: `Foundation/Configs.*`, `Foundation/BaseLog.*`

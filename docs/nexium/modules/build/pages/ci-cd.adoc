= Continuous Integration

`.gitea/workflows/code-quality.yml` currently runs one Linux Clang Debug build on pushes,
inside `cpp-ci:latest`.

. Check out the repository with a shallow clone.
. Synchronize submodules and initialize their pinned revisions recursively, using parallel shallow fetches.
. Configure Ninja with `CC=clang`, `CXX=clang++`, and `CMAKE_BUILD_TYPE=Debug`.
. Build all enabled targets in parallel.

Root defaults disable tests, benchmarks, and 3D. The workflow does not run GCC, Release,
Windows, formatting, clang-tidy, unit tests, Valgrind, header checks, or layer checks.
Compiler versions are not pinned by the workflow's container tag.

Local check helpers remain under `.gitea/`; see xref:cmake-structure.adoc[CMake infrastructure]
for the separate verification targets. Their availability does not mean CI runs them.

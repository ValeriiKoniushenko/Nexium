= Nexium Engine
:page-role: landing

Nexium is a personal C++ game engine and ImGui editor for games made by a team of 1–3 developers.
The current focus is creating 2D games inside this repository, with optional 3D support.

image::main-preview.png[Engine editor,width=100%]

== Current foundation

* OpenGL rendering, orthographic/perspective cameras, grids, textures, and optional meshes.
* Reflected component trees through JustReflectMe.
* ImGui docking, scene tree, property adapters, asset browser, and viewport picking.
* CMake libraries organized into Foundation, Platform, RawBackend, Fundamental, Subsystems, World, Runtime, and Editor.

The example application is editor-enabled.
Game-only building/delivery remains later work.
Render-mode switching currently shares the authored scene; it is not an isolated Play/Stop workflow.

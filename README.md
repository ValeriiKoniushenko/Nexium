## System dependency

### Linux
You need to install next components to build the project.
```
sudo apt install libwayland-dev \
                libx11-dev \
                libxi-dev \
                libxrandr-dev \
                libxinerama-dev \
                libxkbcommon-dev \
                libxcursor-dev \
                libgl1-mesa-dev
```
